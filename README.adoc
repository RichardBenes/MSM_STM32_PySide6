== MEMS chips used
:gyrolnk: footnote:[L3GD20: https://www.st.com/en/mems-and-sensors/l3gd20.html, datasheet: https://www.st.com/resource/en/datasheet/l3gd20.pdf]
:camlnk: footnote:[LSM303C: https://www.st.com/en/mems-and-sensors/lsm303c.html, datasheet: https://www.st.com/resource/en/datasheet/lsm303c.pdf]
:miclnk: footnote:[MP34DT01-M: https://www.st.com/en/audio-ics/mp34dt01-m.html, datasheet: https://www.st.com/resource/en/datasheet/mp34dt01-m.pdf]
:brdlnk: footnote:[STM32L476 Discovery board: https://www.st.com/en/evaluation-tools/32l476gdiscovery.html]

A STM32L476 Discovery board {brdlnk} has been used with following MEMS sensors:

* L3GD20{gyrolnk} -- 3-axis gyroscope
* LSM303C{camlnk} -- compass + 3D accelerometer + 3D magnetometer
* MP34DT01-M{miclnk} -- MEMS microphone
